### projects

| repo | what it does |
| --- | --- |
| [pgp-messenger](https://github.com/kafkaesqueismn/pgp-messenger) | Desktop GUI for encrypting, decrypting, signing and verifying messages & files with OpenPGP (PGPy + PySide6) |
| [pcap-analyser](https://github.com/kafkaesqueismn/pcap-analyser) | Scapy CLI that hunts packet captures for port scans, DNS tunnelling, cleartext creds and unusual ports |
| [static-analyser](https://github.com/kafkaesqueismn/static-analyser) | Inspects files without running them: hashes, file type, PE/ELF headers, entropy, strings, IOCs |
| [log-analyser](https://github.com/kafkaesqueismn/log-analyser) | Hunts SSH auth logs for brute-force attempts and suspicious logins |
| [password-checker](https://github.com/kafkaesqueismn/password-checker) | Python CLI that scores password strength and checks breaches via HIBP's k-anonymity API |
| [cipher-toolkit](https://github.com/kafkaesqueismn/cipher-toolkit) | Classical ciphers (Caesar, Vigenère, XOR) and the attacks that break them |
| [network-scan-detector](https://github.com/kafkaesqueismn/network-scan-detector) | Notebook training a decision tree to detect port scans: a first step into ML for security |
